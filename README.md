# ビカクログ 🌿💧

ビカクシダ（コウモリラン）の **重さ** を記録して、**水やりのタイミング** を教えてくれる無料のアプリです。

- iPhone の Safari で「ホーム画面に追加」すると、ふつうのアプリのように使えます（パソコンのブラウザでも使えます）
- 記録は **あなた自身の Google スプレッドシート** に保存され、iPhone とパソコンで自動で同期されます
- 電波が弱い場所で記録しても、つながったときに自動で保存されます
- 作者を含め、**他の人にあなたの記録が見られることはありません**

**アプリの URL：<https://kushinon.github.io/bikaku-log/>**

## 1. できること

| 機能 | 内容 |
| --- | --- |
| 株の登録 | 名前・品種・写真・置き場所・仕立て（板付け／鉢／ハンギング）・メモ |
| 計量の記録 | 日時・重さ（g）・種別（水やり前／水やり後／ふだんの計量）・メモ。大きな数字キーで片手で数秒で入力できます |
| 水やり判定 | 「水やり前」の重さの記録から **目安重量** を自動で計算（手動で上書きもできます）。直近の重さの減り方から **次の水やり予定日** を予測します |
| 色分け表示 | 一覧画面で 🔴「水やり時期」 🟡「もうすぐ」 🟢「まだ大丈夫」 を色とアイコンで表示します |
| グラフ | 株ごとの重さの推移・水やりのタイミング・目安重量・予測線を表示します |
| まとめて取り込み | Google Keep などに書きためた計量メモを貼り付けるだけで、過去の記録をまとめて登録できます |
| 仕立て直し対応 | 仕立て直し・植え替えで重さが変わっても、それ以降の記録だけで判定します |
| メール通知（任意） | 毎朝7時、「水やり時期」「もうすぐ」の株があるときだけ Gmail に届きます |

## 2. はじめかた

### まずは試してみる（準備不要・1分）

1. iPhone の Safari かパソコンのブラウザで **<https://kushinon.github.io/bikaku-log/>** を開きます。
2. **「サンプルデータで試してみる」** を押します。

サンプルの株3つ（60日ぶんの記録つき）で、一覧・計量・グラフなどをひととおり試せます。
サンプルの記録はその端末の中だけに保存され、どこにも送られません。

### 自分の記録をつけるための準備（約15分）

自分の記録を保存するために、**あなた専用のスプレッドシート** を用意します。
むずかしいプログラミングは不要で、ボタン操作だけです。STEP 3 まではパソコンでの作業をおすすめします。

**用意するもの**：Google アカウント（Gmail のアカウント）、iPhone またはパソコン
（GitHub のアカウントは不要です）

```
 ┌───────────┐       ┌──────────────────┐       ┌───────────────────┐
 │ iPhone    │       │ Google Apps Script│       │ あなたの           │
 │ パソコン   │ ───▶ │（合言葉をチェック）│ ───▶ │ スプレッドシート   │
 │ (アプリ)   │ ◀─── │                  │ ◀─── │                   │
 └───────────┘       └──────────────────┘       └───────────────────┘
   みんな共通の画面          ここから下は、あなたの Google ドライブの中だけ
```

### STEP 1　スプレッドシートを用意する

#### 方法A：ひな形をコピーする（かんたん・おすすめ）

> ひな形のリンクは準備中です。それまでは下の「方法B」で用意してください。

1. パソコンで Google にログインした状態で、ひな形のリンクを開きます。
2. 「**コピーを作成しますか？**」と出るので、**「コピーを作成」** を押します。
   （「添付の Apps Script ファイルもコピーされます」と表示されます。それで大丈夫です）
3. あなたの Google ドライブに「ビカクログ のコピー」ができます。名前は自由に変えてOKです。
4. 開いたスプレッドシートのメニューから **拡張機能 → Apps Script** を開きます。コードがすでに入っています。

→ **STEP 2** へ進みます。

#### 方法B：コードを自分で貼り付ける

1. ブラウザで <https://sheets.new> を開き、新しいスプレッドシートを作ります。名前を「ビカクログ」にします。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 別のタブで <https://raw.githubusercontent.com/kushinon/bikaku-log/main/gas/Code.gs> を開き、
   ページをクリックして **すべて選択**（Windows は `Ctrl`＋`A`、Mac は `⌘`＋`A`）→ **コピー**（`Ctrl`＋`C`／`⌘`＋`C`）します。
4. Apps Script のタブに戻り、最初から入っている `function myFunction() { … }` をクリックして
   **すべて選択 → `Delete` で消して、真っ白な状態** にします。
5. **貼り付け**（`Ctrl`＋`V`／`⌘`＋`V`）して、💾 で保存します。

> ⚠️ `function myFunction() {` を消さずに、その中に貼り付けてしまうと動きません。
> 1行目が `// ===== ビカクログ サーバー用コード` で始まっていればOKです。

### STEP 2　合言葉を決める

1. Apps Script の画面の左端にある **⚙（プロジェクトの設定）** を押します。
2. 「**タイムゾーン**」が **(GMT+09:00) 日本標準時 - 東京** になっているか確認します（違えば選び直します）。
3. 一番下の「**スクリプト プロパティ**」で **「スクリプト プロパティを追加」** を押し、次のように入れます。

   | プロパティ（左） | 値（右） |
   | --- | --- |
   | `PASSCODE` | あなたが決めた **合言葉**（8文字以上の半角英数字がおすすめ。例：`hinata-bikaku-2026`） |

4. **「スクリプト プロパティを保存」** を押します。

> ⚠️ 合言葉は、あとで iPhone やパソコンにも入れます。忘れないように控えておき、他の人には教えないでください。

### STEP 3　ウェブアプリとして公開する（デプロイ）

1. Apps Script の左端の **`< >`（エディタ）** を押してから、右上の青い **「デプロイ ▼」→「新しいデプロイ」** を押します。
2. 「種類の選択」の横の **⚙** を押し、**「ウェブアプリ」** を選びます。
3. 次のように設定して、**「デプロイ」** を押します。

   | 項目 | 設定 |
   | --- | --- |
   | 説明 | `ビカクログ`（空欄でもOK） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

   > 「全員」にしても、合言葉を知らない人はデータを見たり書いたりできません。アプリから通信するために必要な設定です。

4. 「**アクセスを承認**」と出たら、次の順に進みます。
   1. **「アクセスを承認」**（または「権限を確認」）を押す → 自分のアカウントを選ぶ
   2. 「**このアプリは Google で確認されていません**」と出たら、左下の **「詳細」** →
      一番下の **「（プロジェクト名）（安全ではないページ）に移動」** を押す
   3. **「すべて選択」** にチェックを入れて **「続行」**（または「許可」）を押す

   > 💡 この警告は、Google の審査を受けていない **自分のアカウントの中のプログラム** を初めて動かすときに必ず出るものです。
   > このプログラムが使うのは、あなたのスプレッドシートと（通知を使う場合の）あなたのメール送信だけです。

5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）の **「コピー」** を押し、
   自分宛てのメールやメモなどに控えます。iPhone に送っておくと次が楽です。
6. 確認：その URL をブラウザで開くと「**ビカクログのサーバーは動いています。**」と表示されます。

> ⚠️ このウェブアプリの URL も合言葉と同じく、他の人に教えないでください。
> URL をもう一度見たいときは「デプロイ ▼ → **デプロイを管理**」で確認できます（「新しいデプロイ」を押すと別の URL ができてしまいます）。

### STEP 4　iPhone で使う

1. iPhone の **Safari** で <https://kushinon.github.io/bikaku-log/> を開きます。
2. 画面下の **共有ボタン**（四角から上向きの矢印）→ **「ホーム画面に追加」** →「追加」を押します。
3. ホーム画面の **ビカクログ** のアイコンからアプリを開きます。
4. **「接続の設定をする」** を押し、STEP 3 の **ウェブアプリの URL** と STEP 2 の **合言葉** を入れて **「接続して保存」** を押します。
5. 「**接続できました！**」と出れば完了です 🎉

> 💡 **大事**：iPhone では、Safari で開いたときと、ホーム画面のアイコンから開いたときで、保存場所が別々です。
> 接続の設定は **ホーム画面のアイコンから開いたアプリの中で** 行ってください。
>
> 💡 URL は長いので、メールなどで iPhone に送り、長押し →「コピー」→ 入力欄を長押し →「ペースト」が簡単です。

### STEP 5　パソコンでも使う（必要なら）

パソコンのブラウザで <https://kushinon.github.io/bikaku-log/> を開き、同じ URL と合言葉を入れます。
iPhone で入れた記録が表示されれば、同期できています。
（Chrome や Edge では、アドレスバーの右の「インストール」ボタンでアプリのように使うこともできます）

**準備はここまでです。** 一覧画面の「＋ 株を追加」から、あなたの株を登録してください。

## 3. 使い方

### 毎日の流れ

1. ビカクシダをはかりにのせて、アプリの一覧画面で株の **計量** ボタンを押します。
2. 大きな数字キーで重さを入れ、種別を選んで **保存** を押します。
   - **ふだん**：水やりをしない日の計量
   - **水やり前**：これから水やりするときの重さ（＝乾いたときの重さ）
   - **水やり後**：水やりして、水がしたたらなくなったあとの重さ
3. 「水やり前」を保存すると、自動で「水やり後」に切り替わるので、水やり後の重さを続けて記録できます。

> 💡 画面上部の株の名前を横にスクロールして押すと、別の株にすぐ切り替えられます。
> 日時を過去にしたいときは「日時・メモを変更」を開きます。

### 過去の記録を Google Keep などからまとめて取り込む

メモに書きためた計量の記録は、1件ずつ入れなくても **貼り付けるだけで取り込めます**。

1. 先に、その株を「＋ 株を追加」で登録しておきます。
2. 株の詳細画面の一番下（または ⚙ 設定）にある **「メモからまとめて取り込む」** を押します。
3. 取り込む株を選び、Keep のメモを **そのままコピーして貼り付け**、**「読み取る」** を押します。
4. 読み取り結果が一覧で出るので、種別（水やり前／水やり後／ふだん）が正しいか確認し、必要なら右の欄で直します。
5. **「○件を取り込む」** を押します。

読み取れる書き方の例：

```
• 日時: 2026/09/17 21:20
• 重量: 460g
• 9/18 21:48: 304g
• 9/18 22:30: 636g (水やり後)
• 10/4 19:30: 611g (4回目 水やり後)
```

- 1行に「日付・時刻・重さ（g）」があれば読み取ります。「日時: …」と「重量: …」が別々の行でも大丈夫です。
- （ ）の中はメモになります。「水やり」と書いてある行は「水やり後」になります。
- 種別が書いていなくても、前の記録より1割以上重くなっている行は「水やり後」とみなします（「満水」と書いてある行も「水やり後」です）。
- 「水やり後」の直前（6時間以内）の軽い記録は、自動で「水やり前」にします。
- 自動で決めた種別には ※ が付きます。違っていたら右の欄で直してください。
- 年が書いていない日付は、今年（未来の日付になる場合は去年）とみなします。
- 同じ日時・同じ重さの行は1件にまとめます（Keep でメモを何度も書き足して、同じ行が重なっていても大丈夫です）。すでに登録済みの記録はチェックが外れるので、同じメモを2回貼っても二重になりません。

### 仕立て直し・植え替えをしたとき

板を替えたり植え替えたりすると、株の重さががらっと変わります。そのときは、計量画面の **「日時・メモ・仕立て直し ▾」** を開いて
**「仕立て直し・植え替えをした」** にチェックを入れてから保存してください（ふつうは水やり後の重さと一緒に記録します）。

- その記録より **前の記録は、水やり判定（目安重量・予定日）に使わなくなります**。グラフや記録の一覧には残ります。
- メモに「仕立て直し」「植え替え」「板替え」「付け替え」のどれかが入っている記録も同じ扱いです。メモから取り込んだ記録にも効きます。

### 水やり判定のしくみ

- **目安重量**：その株の「水やり前」の記録のうち、**新しい5回ぶんの真ん中の値（中央値）** です。
  株の詳細画面で、手動で上書きすることもできます（「自動に戻す」で元に戻せます）。
- **次の水やり予定日**：最後の「水やり後」より後の計量から、重さの減り方（1日あたり何g減っているか）を計算し、
  目安重量になる日を予測します。水やり直後は余分な水が抜けて急に軽くなるので、「水やり後」の重さそのものは減り方の計算に使いません。
  記録が少ないときは、過去の水やりサイクル（水やり後 → 次の水やり前）の平均を使います。
- **色分け**
  - 🔴 **水やり時期**：目安重量以下になった、または予定日を過ぎた
  - 🟡 **もうすぐ**：予定日まで2日以内、または目安重量の +5% 以内
  - 🟢 **まだ大丈夫**：それ以外
  - ⚪ **記録が足りません**：「水やり前」の記録がまだない（目安重量を手動で入れれば判定できます）

> 予測をよくするコツ：「水やり前」と「水やり後」をセットで記録し、ふだんの計量も1〜2日に1回あると精度が上がります。

### 同期の表示（画面右上）

| 表示 | 意味 |
| --- | --- |
| 🟢 同期済み | すべての記録がスプレッドシートに保存されています |
| 🟡 未送信 ○件 | 端末に保存済みで、送信を待っています（自動で送られます） |
| 🟡 オフライン | 電波がありません。つながると自動で送ります |
| 🔴 同期エラー | 合言葉やURLを確認してください（⚙ 設定に詳しい内容が出ます） |

表示を押すと、すぐに同期を試します。

## 4. 困ったとき

<details>
<summary><b>「接続できませんでした」と出る</b></summary>

- URL が `https://script.google.com/macros/s/` で始まり `/exec` で終わっているか確認してください。
- STEP 3 の「アクセスできるユーザー」が **全員** になっているか確認してください。
- 電波の状態を確認してください。
</details>

<details>
<summary><b>「合言葉が違います」と出る</b></summary>

- STEP 2 の `PASSCODE` と、アプリに入れた合言葉が完全に同じか確認してください（大文字・小文字、空白も区別されます）。
- 20回続けて間違えると、安全のため10分ほど受け付けが止まります。少し待ってからやり直してください。
</details>

<details>
<summary><b>「サーバーに合言葉（PASSCODE）が設定されていません」と出る</b></summary>

STEP 2 のスクリプト プロパティに `PASSCODE` を追加して保存してください。
</details>

<details>
<summary><b>合言葉を変えたい</b></summary>

1. Apps Script の ⚙ プロジェクトの設定 → スクリプト プロパティで `PASSCODE` の値を変えて保存します。
2. iPhone とパソコンのアプリで、⚙ 設定 → 合言葉 を新しいものにして「接続して保存」を押します。
</details>

<details>
<summary><b>スプレッドシートを直接編集した／行を消した</b></summary>

アプリの ⚙ 設定 → **サーバーから全データを読み直す** を押してください。
（ふだんはスプレッドシートを直接編集する必要はありません）
</details>

<details>
<summary><b>朝の通知が来ない</b></summary>

- 「水やり時期」「もうすぐ」の株がない日は送られません。「[毎朝の通知メールを使う](#毎朝の通知メールを使う)」の `testNotice` でメールが届くか確認してください。
- 迷惑メールフォルダに入っていないか確認してください。
- Apps Script の左端 **⏰（トリガー）** に `sendMorningNotice` があるか確認してください。なければ `setup` をもう一度実行します。
</details>

<details>
<summary><b>サーバー用のコード（gas/Code.gs）が更新されたとき</b></summary>

アプリの新しい機能でサーバー側の変更が必要なときだけ、お知らせします。ふだんは何もしなくて大丈夫です。

1. 「[方法B](#方法bコードを自分で貼り付ける)」と同じように、Apps Script のコードを新しい `gas/Code.gs` の内容に **全部置き換えて** 保存します。
2. **デプロイ → デプロイを管理** を開き、右上の **✏️（編集）** を押します。
3. 「バージョン」で **新バージョン** を選んで **デプロイ** を押します。

この方法なら **ウェブアプリのURLは変わらない** ので、iPhone やパソコンの設定はそのままで大丈夫です。
（「新しいデプロイ」を作るとURLが変わるので注意してください）
</details>

<details>
<summary><b>アプリの画面が新しくならない</b></summary>

- ⚙ 設定の **「最新版に更新する」** を押してください（ver.1.2.1 以降）。記録のデータは消えません。
- そのボタンがない古い版のときは、アプリを完全に閉じて（iPhone では画面の下から上にスワイプし、アプリを上に払う）開き直してください。
  GitHub に反映されてから最大10分ほどは古い画面が出ることがあるので、少し待ってから開き直すと確実です。
</details>

写真はスプレッドシートの1つのセルに入るよう、アプリが自動で小さく（長辺480ピクセル程度）してから保存します。
</details>

## 5. 安全とプライバシー

- アプリの画面（GitHub Pages）はみんなで共通ですが、**記録は各自の Google スプレッドシートにだけ保存されます**。
  アプリが通信するのは、あなたが設定したウェブアプリの URL（あなたの Apps Script）だけで、作者のサーバーなどには送られません。
- ウェブアプリの URL と合言葉は、各端末（iPhone・パソコン）の中だけに保存されます。
- データの読み書きは、合言葉が合っているときだけできます。合言葉を何度も間違えると、しばらく受け付けを止めます。
- スプレッドシートはあなたの Google ドライブにあり、共有しない限り他の人は見られません。
- このアプリのコードはすべて公開されているので、何をしているか誰でも確認できます。
- 合言葉やウェブアプリの URL は、SNS や GitHub の Issue などに書き込まないでください。
